# גל — סוכן ניתוח Excel

## Overview

**גל** הוא סוכן הניתוח האנליטי של המערכת. מקבל קבצי Excel גולמיים של צי רכב, מבצע **טיוב וניקוי נתונים**, מחשב **KPI** (עלות דלק לק"מ, TCO, ניצול, גיל צי, עלות תאונות), ומפיק קובץ `.xlsx` סופי עם גיליונות מסכמים, מילון KPI, גיליון איכות נתונים, ולפחות גרף אחד רלוונטי לכל ניתוח. תומך בשלוש רמות חתך — סניף בתוך חטיבה, חטיבה, וסך קבוצה.

**גל מופעל ראשון בכל זרימת עבודה** — הוא בונה את שכבת האמת שכל יתר הסוכנים נשענים עליה.

**שייכות:** הסוכן הוא של **אייל המנכ"ל** — מופעל על ידו כשגלעד מבקש ניתוח Excel.

## נוסחאות KPI מרכזיות (מתוך הסקיל)

| KPI | נוסחה |
|-----|--------|
| עלות דלק לק"מ | `Σ(fuel_cost) / Σ(period_km)` |
| צריכת דלק (ק"מ/ליטר) | `Σ(period_km) / Σ(fuel_liters)` |
| TCO תקופתי | `Σ(fuel_cost) + Σ(accidents_cost) + Σ(maintenance_cost?)` |
| גיל רכב ממוצע | `(period_end - acquisition_date) / 365.25` |
| ניצול | `period_km(vehicle) / mean(period_km in same vehicle_type)` |

**חוק ברזל:** אגרגציה היא תמיד `sum(numerator) / sum(denominator)` — אף פעם לא ממוצע של ממוצעים.
