# Fleet Analysis System — מערכת ניתוח צי רכב

מערכת multi-agent של G1-Group לניתוח נתוני צי רכב מקבצי Excel והפקת תוצרים ניהוליים מוכנים (Excel, PowerPoint, Word, PDF).

## מה הפרויקט עושה

הפלטפורמה מקבלת קבצי Excel של צי בן ~600 כלי רכב המאוגדים בהיררכיית **קבוצה → חטיבה → סניף**, מטייבת ומאחדת את הנתונים, מחשבת KPI מרכזיים (עלות דלק לק"מ, TCO, ניצול, גיל צי, עלות תאונות), ומפיקה תוצרים ניהוליים בארבעה פורמטים — בעברית RTL, פונט Tahoma 11.

## הצוות הדיגיטלי

| סוכן | תפקיד | תוצר |
|------|--------|------|
| **אייל** | מנכ"ל דיגיטלי, מתאם | סיכומים ניהוליים, הקצאת משימות |
| **גל** | אנליסט Excel | `.xlsx` עם KPI, פילוחים וגרפים |
| **אירית** | מצגות הנהלה | `.pptx` של 10-14 שקפים עם תובנות והמלצות |
| **בר** | כותב דוחות | `.docx` מובנה — תקציר מנהלים, ניתוח לפי רמות, מסקנות |
| **ברק** | מפיק PDF | `.pdf` סופי עם חותמת זמן, גרסה ו-Header/Footer |

זרימת עבודה: גלעד (משתמש אנושי) פונה לאייל → אייל מפעיל את גל ראשון → סוקר ממצאים → מפעיל אירית/בר/ברק לפי הצורך → מאחד תוצרים ומחזיר לגלעד.

## הפעלה

הפרויקט רץ בתוך **Claude Code**. השיחה הראשית היא אייל. כדי לקרוא לסוכן ספציפי בלי לעבור דרך אייל, אפשר להפעיל אותו ישירות דרך Agent tool של Claude Code.

```
> אייל, אנא הפק לי דוח רבעוני על חטיבת הצפון לפי קבצי ה-Excel ב-input/
```

## דרישות

- **Claude Code** — המערכת רצה בתוך השיחה.
- **Python 3** עם `pandas` ו-`openpyxl` — לעיבוד מקדים של Excel (גל עשוי להפעיל).
- **PRD מלא:** `OneDrive/Claude/רכב/PRD עבור פרוייקט ניתוח למחלקת הרכב1.docx` — מקור האמת להגדרות KPI, הרשאות, וקריטריוני קבלה.
