# Skill — gal-excel-fleet-analyst

ידע תפעולי מלא לסוכן **גל**. קרא אותו בתחילת כל משימה. סקיל זה הוא ה-source of truth לחישובים — אסור לסטות מהנוסחאות כאן ללא אישור מפורש מאייל.

## 2. אלגוריתם טיוב נתונים (סדר חובה)

1. **מחיקת שורות ריקות** — כל שורה ללא `vehicle_id` או ללא ערך מספרי אחד לפחות.
2. **נרמול `vehicle_id`** — הסר רווחים, מקפים, אפסים מובילים. שמור כמחרוזת.
3. **נרמול תאריכים** — תמיכה ב-`DD/MM/YYYY`, `YYYY-MM-DD`, `DD.MM.YYYY`, Excel serial. פלט תמיד `DD/MM/YYYY`.
4. **נרמול מספרים** — הסר `₪`, `,`, רווחים. המר ל-float. ערכים שליליים בעלויות → סמן ב-`איכות נתונים` (לא למחוק).
5. **איחוד ערכים מילוליים** — בנה מילון נרמול לסניפים/חטיבות (לדוגמה `"ת"א"` / `"תל-אביב"` / `"TLV"` → `"תל אביב"`). אם זוהה מקרה חדש שלא קיים במילון — בקש אישור מגלעד.
6. **בניית `period_km`** — לכל רכב, מיין לפי תאריך וחשב `odometer[i] - odometer[i-1]`. ערכים שליליים → איכות נתונים.
7. **זיהוי כפילויות** — מפתח: `(vehicle_id, date, fuel_liters, fuel_cost)`. כפילות מלאה → השאר אחת. כפילות חלקית → סמן.
8. **זיהוי חריגים סטטיסטיים** — לכל KPI, חשב mean ± 3*std. ערכים מחוץ → סמן ב-`איכות נתונים` אבל **אל תזרוק**.

## 3. נוסחאות KPI (קנוניות)

לכל KPI, חישב בכל אחת מהרמות: `vehicle` / `branch` / `division` / `group`. הצג תמיד עם יחידה ותקופה.

### עלות דלק לק"מ
```
fuel_cost_per_km = Σ(fuel_cost) / Σ(period_km)
```
**אם** `Σ(period_km) = 0` → סמן N/A, אל תחלק.

### צריכת דלק ממוצעת (ק"מ לליטר)
```
km_per_liter = Σ(period_km) / Σ(fuel_liters)
```
ערך נמוך מ-3 או גבוה מ-30 → חריג, סמן.

### עלות תאונות
```
accidents_cost_total = Σ(accidents_cost)
accidents_rate = Σ(accidents_count) / count(distinct vehicle_id)
```

### TCO (Total Cost of Ownership) — תקופתי
```
TCO = Σ(fuel_cost) + Σ(accidents_cost) + Σ(maintenance_cost if exists)
TCO_per_km = TCO / Σ(period_km)
```
ציין מפורשות אם נתוני תחזוקה חסרים — TCO יסומן "חלקי".

### גיל רכב ממוצע
```
vehicle_age_years = (period_end - acquisition_date) / 365.25
fleet_avg_age = mean(vehicle_age_years across active vehicles)
```

### ניצול רכב
```
utilization_ratio = period_km(vehicle) / mean(period_km across fleet in same vehicle_type)
```
- `< 0.5` → תת-ניצול
- `> 1.5` → ניצול-יתר

### השוואה תקופתית
```
YoY = (current_period - same_period_last_year) / same_period_last_year
MoM = (current_month - prev_month) / prev_month
```

## 4. חוקי אגרגציה לפי היררכיה

- **סניף** = קבוצת רכבים עם אותו `branch`.
- **חטיבה** = איחוד כל הסניפים עם אותו `division`. **אגרגציה היא סכום נומרטור וסכום דנומינטור** (לא ממוצע של ממוצעים). לדוגמה: `fuel_cost_per_km` ברמת חטיבה = `Σ(fuel_cost) של כל הסניפים / Σ(period_km) של כל הסניפים`.
- **קבוצה** = איחוד כל החטיבות, באותו עיקרון.

**חוק ברזל:** אל תחשב ממוצע של ממוצעים. תמיד חזור לנומרטור ולדנומינטור הגולמיים.

## 5. טמפלייט גיליונות חובה ב-Excel הפלט

| גיליון | תוכן |
|--------|------|
| `סיכום מנהלים` | KPI קבוצתיים בכרטיסים, 3 ממצאים מרכזיים, גרף מפתח אחד |
| `קבוצה` | KPI מלאים ברמת הקבוצה |
| `חטיבות` | טבלה: שורה לכל חטיבה, עמודה לכל KPI |
| `סניפים` | טבלה: שורה לכל סניף, עם `division` כעמודה ראשונה. ממוין לפי חטיבה |
| `רכבים` | טבלה: שורה לכל רכב עם כל ה-KPI (לפי הצורך — יכול להיות סינון top/bottom 50) |
| `נתונים מטוייבים` | הנתונים אחרי טיוב, עם עמודה `source_file` ו-`source_row` |
| `מילון KPI` | שם KPI, הגדרה, נוסחה, יחידה |
| `איכות נתונים` | שורות שסומנו: חוסרים, כפילויות, ערכים שליליים, חריגים סטטיסטיים, סיבה |
| `מקורות נתונים` | שמות קובצי מקור, גיליונות, תאריך קליטה, מספר רשומות שנקלטו |
